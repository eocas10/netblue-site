Lo que hay que llevarse

Una sola vía

Del hash no se puede volver a la contraseña. Por eso el sistema verifica repitiendo el cálculo, nunca descifrando.

Sal única

Impide las rainbow tables y evita que se note quién comparte contraseña. Se guarda en claro junto al hash.

Lento a propósito

Algoritmos como PBKDF2, bcrypt o Argon2id cuestan tiempo. MD5 o SHA-256 solos son demasiado rápidos para contraseñas.

Tu parte

Ningún hash salva una contraseña corta o repetida. Usa frases largas, un gestor de contraseñas y MFA.
