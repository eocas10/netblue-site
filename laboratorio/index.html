Cómo usar este laboratorio en una sesión

  1. Empiece por Ingeniería social: es la amenaza que más afecta a todo el personal.
  2. Proyecte cada simulador y deje que el grupo proponga la respuesta antes de revelar el resultado.
  3. En los de contraseñas, compare una clave débil con una frase de paso larga para que el contraste quede claro.
  4. Cierre cada tema leyendo juntos las defensas que aparecen al final de cada simulador.
